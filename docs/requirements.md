# DSH 学术数据工作台 · 需求分析

> 版本 0.2 · 状态：待确认。本文是需求分析，不是施工清单；确认关键决策后再进入架构与实现。

## 1. 背景与问题

目标：为「学术级数据科学 + 数据可视化」做一个可独立操作的工作台。

当前实现（v0.1.x）的问题：**面板只有只读展示，没有交互入口**。数据审计、统计推断、出图全部只能靠 Agent 在会话里调用 `lab_*` 工具完成，面板不能选文件、不能触发审计、不能配置统计/出图参数。这不符合「工作台」的预期——用户期望一个能直接上手操作、不依赖对话的界面。

## 2. 目标用户与场景

| 用户 | 场景 |
| --- | --- |
| 研究者 / 数据分析师 | 把实验数据（CSV/XLSX）放进来 → 先看数据质量 → 跑组间比较/回归/相关 → 出期刊栏宽的图 → 导出、复现 |
| 需要"再来一遍"的人 | 同一份数据换参数重跑（换分组、换校正方法、换期刊版式），不想每次重新用自然语言描述 |

两条使用路径需要并存：

1. **面板路径**（本次要补的）：表单驱动，参数明确、可重复、不依赖 LLM。
2. **会话路径**（已有）：Agent 用 `lab_*` 工具驱动，适合描述性/探索性需求。

两条路径必须共享**同一个计算引擎和同一份运行台账**，不能出现两条路算出不一样结果的局面。

## 3. 目标（Goals）

1. 面板能独立完成最小闭环：**选数据 → 审计 → 统计 → 出图 → 查看/下载产物**，全程不需要会话。
2. 会话路径能力不变，与面板路径收敛到同一引擎、同一台账。
3. 复现性：每次运行记录数据指纹、完整参数、Python 与包版本、产物路径，可回看。
4. 数据文件只读；产物落在数据目录，可选复制到工作区。

## 4. 非目标（Non-goals）

- 不复制聊天界面；会话通过宿主原生节点在抽屉里按需出现。
- 不重造统计库；计算交给 numpy / scipy / statsmodels。
- 不做交互式 canvas 图表编辑器（框选缩放、拖拽）——那是 chartlab / smart-charts 的领域，本工作台定位是**出版级静态图**。
- 不做文献库、投稿、LaTeX——那是 sciwork / mimir 的领域。

## 5. 最小闭环（MVP 流程）

```
[数据] 选择/登记一个数据文件 → 自动审计
   ↓
[审计] 逐列统计、缺失/异常/重复/共线、预警
   ↓
[统计] 选分析类型 + 变量/参数 → 效应量、95% CI、p、前提检查
   ↓
[出图] 选图表 + 变量 + 期刊 + 误差棒 → 预览 + 下载 PDF/SVG/PNG
   ↓
[台账] 按数据集/类型回看历史运行与产物
```

## 6. 功能需求（FR）

### F1 数据入口
- F1.1 列出可选数据文件：来自数据目录与当前工作区（只枚举 `csv/tsv/txt/xlsx/xls/json/jsonl/parquet`）。
- F1.2 登记一个文件：解析 + 生成指纹 + 立即审计，登记进 `datasets/`。
- F1.3 数据集列表：名称、行×列、sha256 前缀、审计预警摘要。
- F1.4 不静默创建目录；如需让用户选目录，走宿主目录选择器（见 §9 待确认项）。

### F2 审计
- F2.1 查看逐列统计：类型、n、缺失率、min/q1/median/q3/max/mean/sd、异常值、top 值。
- F2.2 整表指标：重复行、强相关（|r|≥0.8）、预警（缺失>20%、常量列、n<30 等）。
- F2.3 审计结果以可读卡片/表呈现（复用现有 `profile` 输出，改为结构化渲染）。

### F3 统计
- F3.1 表单选择分析类型：describe / compare / associate / regress / chisq。
- F3.2 参数：DV、分组变量、预测变量、x/y、方法（auto/welch/student/mannwhitney/anova/kruskal）、多重比较校正（holm/bh/none）、alpha、robust。
- F3.3 结果卡：效应量 + 95% CI + p（含校正后）+ 前提检查（正态/方差齐性/VIF/异方差）+ warnings。
- F3.4 结果可复制参数到会话（可选），便于"在对话里继续问"。

### F4 出图
- F4.1 表单选择图表：bar / line / scatter / box / violin / raincloud / hist / heatmap。
- F4.2 参数：x/y/分组、误差棒（ci95/sem/sd/none）、期刊（nature/science/ieee/aps/plos/generic）、标题/轴标签。
- F4.3 预览（SVG/PNG）+ 下载 PDF/SVG/PNG + 图注（含 n、单位、数据指纹）。
- F4.4 产物写入数据目录 `figures/<runId>/`，可选 `copyTo` 工作区 `figures/`。

### F5 运行台账
- F5.1 运行历史：id、数据集、分析类型、结论 headline、时间、产物。
- F5.2 按数据集 / 类型筛选；单击回看完整参数与产物。
- F5.3 复现说明：输入指纹、参数、Python 与包版本。

### F6 会话（已有，保留）
- F6.1 「AI 协助」抽屉；会话只在点击时创建/恢复，不常驻。

## 7. 非功能需求（NFR）

- **N1 大文件**：百万行只审计元数据（分块/采样），不把整表拖进浏览器；面板表格分页。
- **N2 只读**：数据文件永不改写；产物只写数据目录（+ 可选工作区副本）。
- **N3 安全**：路径必须收敛在工作区/数据目录内；绝对路径、`..` 逃逸、越界一律拒绝（已有测试断言）。
- **N4 性能**：审计/统计/出图在数秒内返回；面板 12s 轮询 + 手动刷新。
- **N5 一致性**：面板与 Agent 工具调用同一个 `lab_runner.py`，禁止两套算法。
- **N6 可访问性**：中英文、长标题/标签不溢出，窄容器下多列重排。

## 8. 约束（宿主协议）

- 客户端是单文件构建产物，`require` 只拿共享基线 + 已加载插件；React 用 `h()` 构造。
- 面板 props：`{ service, entry, active, conversation }`；`customFrame: true` 整页。
- 工作台不得静默建目录、不得自造聊天界面、首次进入不得自动创建会话。
- 数据目录由 `cordis.patch.yml` 的 `dshHomePath('academic-lab')` 注入。

## 9. 风险与待确认项

- **R1 目录/文件选择器**：宿主只暴露了工作区创建用的 `ctx.uiWorkspace.pickDirectory()`，未确认是否开放给面板 `service`；面板级文件选择器未发现。→ 影响 F1 的交互形态（见决策 D2）。
- **R2 大文件传输**：审计结果若含每列明细，JSON 体积需控制。
- **R3 Python spawn**：宿主进程每次计算 spawn 系统解释器的成本与可靠性（冷启动 ~百 ms 级，可接受）。

## 10. 关键决策（待确认后进入架构与实现）

- **D1 交互主力**：面板表单为主 + 会话为辅（推荐）？还是维持 Agent 为主、面板做控制台？
- **D2 数据入口**：列出数据目录/工作区已有文件供选择（最稳、无宿主文件选择器依赖）？还是尝试宿主目录选择器？
- **D3 出图交互**：参数表单 + 静态出版级图（推荐）？还是需要交互式 canvas？
